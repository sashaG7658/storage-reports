приложение служит для получения наличия товаров на складах ozon и wb, код составляет таблицу в формате excel отмечая наличие позиций в магазинах. для работы в config.py надо прописать api и артикулы товаров которые интересуют. 

The application is used to obtain the availability of goods in the warehouses of ozon and wb, the code creates a table in excel format noting the availability of items in stores. to work in config.py it is necessary to register the api and the articles of the products that you are interested in.

p.s. The API can be updated (api могут быть обновлены и не работать)
